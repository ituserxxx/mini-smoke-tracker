# 吸烟刺客（mini-smoke-tracker）

一款「记录吸烟、看清健康代价」的微信小程序。科幻 HUD 风格界面，数据云端同步。

## 功能

- **记录**：一键打卡 +1，支持诱因标签（随手 / 压力 / 社交 / 放松 / 无聊）、地点与备注
- **战绩**：连续达标天数、累计花费（负值呈现）、少抽支数、近 14 天趋势图、徽章墙与周复盘
- **健康**：基于 WHO / CDC / BMJ 等公开研究的伤害换算（每支烟约 −11 分钟预期寿命），戒烟恢复时间轴 12 个里程碑实时进度
- **分享**：按时间段（最近 7 天 / 30 天 / 3 个月 / 半年 / 1 年）生成科幻风战绩海报，可保存相册或转发好友
- **我的**：每日限额、单包价格、每包支数、戒烟模式等目标设置

## 技术栈

- 微信原生小程序（WXML / WXSS / JS，无框架）
- 后端：WorkBuddy 云服务（托管 PostgreSQL + 微信登录鉴权 + 行级安全 RLS）
- SDK：`@tencent-ai/workbuddy-cloud-sdk/miniprogram`

## 本地开发

1. 微信开发者工具导入本目录（appid 见 `project.config.json`）
2. 菜单「工具 → 构建 npm」
3. 编译预览

## 目录结构

```
├── app.js / app.json / app.wxss   # 全局入口与科幻 HUD 设计 token
├── pages/
│   ├── index/                     # 首页（快速打卡 + 概览）
│   ├── record/                    # 记录（诱因 / 地点 / 备注）
│   ├── stats/                     # 战绩（趋势 / 徽章 / 复盘 / 健康代价）
│   ├── health/                    # 健康统计（伤害换算 + 恢复时间轴）
│   ├── share/                     # 战绩海报（canvas 绘制，时间段筛选）
│   ├── profile/                   # 我的（目标设置 / 数据管理）
│   └── login/                     # 微信一键登录
├── utils/
│   ├── cloud.js                   # 云客户端初始化（仅公开配置）
│   ├── auth.js                    # 会话门禁与登录
│   ├── storage.js                 # 云数据库读写层
│   ├── calc.js / health.js        # 战绩与健康换算（纯函数）
│   └── date.js                    # 日期工具
└── assets/avatar.png              # 小程序头像
```

## 数据来源说明

健康换算基于公开群体层面研究（BMJ 2000、WHO《戒烟的健康益处》、CDC 等），仅用于自我认知与激励，不构成个人医学建议。
